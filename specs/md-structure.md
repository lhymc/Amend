# MD 结构:标题、分割线与操作机制

> Source: Deep Interview, 2026-08-15

## Key Points
- 一份试卷 = 一个 md 文件。
- **文章块**:每篇文章一个二级标题(如 `## 阅读A`),块间用 `---` 分隔;调序 = 大纲里拖拽/剪切整个标题块。
- **删题**:每道题用 HTML 注释边界包裹:
  ```markdown
  <!-- q21 -->
  21. A. decent B. tolerant C. distant D. selfish
  <!-- /q21 -->
  ```
  删除 = 删掉整个注释块,不用框选文字。
- **完形/语法填空**:正文带空位 + 选项表**逐题一行**(`21. A.… B.… C.… D.…`),行号即题号。
