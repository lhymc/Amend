# 概览:角色与目标

> Source: Deep Interview, 2026-08-15

## Key Points
- 现状:跑 ocr.py(PaddleOCR-VL-1.6)得到按页拆分的 `output/doc_N.md`,再手工清理噪声、调整格式。
- 目标:构建"试卷图片 → 结构化错题 md"的工作流,减少手工清理。
- 用途:**打印复习** + **存档查看**(明确不要 Anki 制卡 → 不需要按卡片切块)。
- 编辑环境:VS Code / Obsidian / Typora 三选或多选 → 依赖原生 markdown 结构(标题、`---`、折叠、大纲)实现"易调序、快删题",而非专用 GUI。

## 对设计的约束
1. 输出必须是纯 md,可打印、可存档。
2. 调序/删题要落在编辑器原生能力上(标题块 + 分割线),降低学习成本。
3. 颗粒度设计不需要迁就 Anki 卡片,但删除单题仍需"整块删"而非框选。
