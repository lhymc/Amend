# 综合摘要:Amend 错题录入工作流

> Source: Deep Interview, 2026-08-15(8 轮)

## 一句话
把高中英语试卷扫描件(PDF/图片)批量转成**可打印、易调序、快删题**的结构化错题 md,纯规则先行,LLM 后处理可选。

## 完整流程
```
input/ (PDF/图片, 批处理)
  → src/ocr.py      PaddleOCR-VL-1.6 API(复用 ~/Desktop/.drop/ocr.py)
  → 纯规则清洗       去重 / 剥答案 / 下划线判定 / 序号补全 / 保留配图
  → 结构化           文章块 ## 标题 + --- 分隔 + <!-- qNN --> 注释边界
  → output/YYYY-MM-DD-输入名.md  +  report.md 清洗报告
  → (可选) src/fill.py  完形非错题:选项行标 → A 后填回正文(加粗),删选项行
  → (可选) src/llm.py   后处理,默认关闭
```

## 核心决策(访谈对齐)
| 维度 | 决策 |
|---|---|
| 文件粒度 | 一份试卷 → 一个 md |
| 文章粒度 | `##` 二级标题块,`---` 分隔,大纲拖拽调序(需求 5) |
| 删题 | `<!-- qNN -->` 注释边界,整块删,不框选(需求 7) |
| 题型 | 阅读 / 七选五 / 完形 / 语法填空 |
| 内容字段 | 只留题目(正文+选项,无答案/解析/错因) |
| 空位 | 保留 LaTeX `$ \underline{21} $` |
| 下划线 | 手写线删除;数字序号、词义猜测目标词保留(需求 6) |
| 语法填空编号 | 保留原序号,缺失则问首序号后自动递增 |
| 完形填回 | 选项行标 `→ A` → 脚本填 `**decent**` 入正文,删选项行(非错题) |
| 跨页合并 | 标题驱动,同题型后续页追加到当前块 |
| 配图 | 保留图片引用 |
| 管线 | 纯规则 v1,LLM 可选 |
| 报告 | output/report.md:删除项/去重/剥离/缺失题号/填充清单 |
| 命名 | `YYYY-MM-DD-输入名.md` |

## 需求映射
1. 输出 md ✓  2. 先对齐颗粒度(本访谈即规格)✓  3. `---` 分文章 ✓
4. 全图片 PDF 输入 ✓(API 原生收 PDF)  5. 文章易调序 ✓(二级标题+大纲)
6. 手写下划线不保留(两例外)✓  7. 快速删题 ✓(注释块)
+ 完形部分题可填回原文(非错题)✓
